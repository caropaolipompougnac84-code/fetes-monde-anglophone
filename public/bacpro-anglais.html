Refine professional expression

The aim is to replace ordinary formulations with more precise and professional ones.

Reformulation exercise

Ordinary : There is a problem.

Precise : An issue has arisen.

Ordinary : I did the work.

Precise : The task has been completed.

Ordinary : We need to check.

Precise : A verification is required.

Task: reformulate three ordinary sentences using more precise vocabulary.

Oral

Describe a professional situation using at least two refined expressions. Record the presentation.
