Décrire un geste

Regarder une courte vidéo d’un geste professionnel.

Noter les mots utiles.

Dire ou écrire ce que l’on fait, dans l’ordre.

Mots utiles

Actions : prendre — poser — visser — couper — brancher

Suite : d’abord — ensuite — après — enfin

Exemple

D’abord, je prends le câble.

Ensuite, je le branche.

Enfin, je visse.

Oral

Enregistrer une courte description du geste vu.

Utiliser au moins deux mots de suite.
